# AGENTS.md

TanStack Start app (SSR): Vite 8 + React 19 + TypeScript. No `index.html`/`main.tsx` — file-based routing drives everything. Entry: `src/router.tsx` (creates router + `Register` types) → `src/routes/__root.tsx` (HTML shell) → route files in `src/routes/`. Stack uses shadcn + Tailwind v4 with Radix UI primitives.

## Commands (pnpm only)

- `pnpm dev` — TanStack Start dev server on `:3000` (custom port in `vite.config.ts`, not the Vite default).
- `pnpm preview` / `pnpm build` (outputs `dist/`) / `pnpm lint`.
- Node 24 required (`engines`); pnpm 10.33.2 pinned. CI installs with `--frozen-lockfile`, so update `pnpm-lock.yaml` deliberately.
- No test runner. Verify with `pnpm lint` + `pnpm build`; typecheck with `pnpm exec tsc --noEmit` (not wired into a script).

## Routing (TanStack Router, file-based)

- Routes live in `src/routes/`: `__root.tsx` is the root route (defines the HTML shell via `HeadContent`/`Scripts`), `index.tsx` maps to `/`. New route = new file, wired up automatically.
- `src/routeTree.gen.ts` is auto-generated by the `tanstackStart()` Vite plugin (on dev/build) — never hand-edit; it's excluded from ESLint. No `tsr` CLI is installed.
- SSR: route code runs on server and client. Guard browser-only globals (`window`/`document`); use TanStack Start server APIs for server-side logic.

## Data fetching (TanStack Query + SSR)

- App uses TanStack Query v5 wired to the router via `@tanstack/react-router-ssr-query`.
- The `QueryClient` is created per call in `getRouter()` (`src/router.tsx`), passed into the router `context`, and connected with `setupRouterSsrQueryIntegration()`. Do not hoist it to a module-level singleton — that would leak query cache across SSR requests.
- Route loaders get it via `context.queryClient`; thread the `RouterContext` type (exported from `src/router.tsx`) through `createRootRouteWithContext<RouterContext>()` in `__root.tsx`.

## UI components (shadcn + Radix UI)

- Components live in `src/components/ui`, generated by the shadcn CLI — add new ones with `pnpm exec shadcn add <name>`, don't hand-roll.
- `components.json`: style `radix-nova` → primitives are **Radix UI** (unified `radix-ui` package), not Base UI; icons are remixicon (`@remixicon/react`).
- `cn` helper lives at `@/styles/utils` (aliases map both `utils` and `lib` to `@/styles`), not `@/lib/utils`.

## Lint & formatting

- ESLint (antfu config) is the only formatter — no Prettier. `pnpm lint` = `eslint .` reports fixable style errors; auto-fix happens on save in VSCode (`source.fixAll.eslint`), or run `pnpm exec eslint --fix .`.
- Style: 2-space indent, double quotes, semicolons. Import order is enforced by `perfectionist/sort-imports` — do not run "Organize Imports"; it fights the rule (VSCode sets `source.organizeImports` to `never`).

## TypeScript constraints (strict)

- `verbatimModuleSyntax`: type-only imports must use `import type`.
- `erasableSyntaxOnly`: no enums, namespaces, or parameter properties.
- `noUncheckedIndexedAccess`: index access yields possibly `undefined`.
- Path alias `@/*` → `./src/*`; Vite resolves tsconfig paths natively (no plugin needed).

## Styling

- Tailwind CSS v4 via `@tailwindcss/vite` — no `tailwind.config`. Theme via CSS (`@theme`) in `src/styles/global.css`, which also imports `tw-animate-css` and `shadcn/tailwind.css`. The stylesheet is pulled into the app via `@/styles/global.css?url` imported in `src/routes/__root.tsx` (no `<link>` in an HTML file).

## CI

- `.github/workflows/ci.yaml`: `pnpm lint` + `pnpm build` on PRs and pushes to `main`.

## Agent skills

- The repo bundles TanStack Router/Start skills under `.agents/skills/` (`router-core`, `start-client-core`, `react-router`, `router-query`, etc.). They're pinned to the current APIs used here — load the matching skill before writing router, data-fetching, or server-function code.
